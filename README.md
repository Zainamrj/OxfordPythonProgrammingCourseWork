# Python Programming for Data Science — Oxford University Coursework

Final coursework for the **Python Programming for Data Science: Introduction** course at the University of Oxford (Oct – Dec 2025).

## Overview

This project demonstrates end-to-end data analysis using Python — from raw data ingestion and cleaning through to transformation, statistical analysis, and visualisation. The work is structured as a series of Jupyter Notebooks, each building on the last to produce a clean, reproducible analytical pipeline.

## What's covered

- **Data cleaning & preprocessing** — handling missing values, outliers, and inconsistent formats using Pandas
- **Data transformation** — reshaping, filtering, grouping, and aggregating datasets for analysis
- **Statistical analysis** — summary statistics, distributions, and pattern identification using NumPy
- **Data visualisation** — charts, plots, and trend analysis using Matplotlib
- **Reproducible pipelines** — all analysis documented in Jupyter Notebooks for clarity and reproducibility

## Tech stack

| Tool | Purpose |
|------|---------|
| Python 3 | Core language |
| Pandas | Data manipulation and cleaning |
| NumPy | Numerical computation and statistics |
| Matplotlib | Data visualisation |
| Jupyter Notebook | Interactive analysis and documentation |

## How to run

1. Clone the repo:
   ```bash
   git clone https://github.com/Zainamrj/OxfordPythonProgrammingCourseWork.git
   cd OxfordPythonProgrammingCourseWork
   ```

2. Install dependencies:
   ```bash
   pip install pandas numpy matplotlib jupyter
   ```

3. Launch Jupyter:
   ```bash
   jupyter notebook
   ```

4. Open the notebooks in order and run all cells.
